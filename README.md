# 上海迪彼电子科技有限公司官方网站

企业官方网站前端项目，采用原生 **HTML、CSS、JavaScript** 构建，展示公司简介、核心解决方案、产品信息、技术能力及联系方式，并提供 ANC 主动降噪交互演示。

当前视觉改版方向为 **蓝白极简商务风**：以白色和浅蓝色为主背景、商务蓝为强调色，突出企业专业形象与内容可读性。

> 本仓库主要存放网站前端静态资源。项目目前不依赖 React、Vue 等前端框架，也没有配置 npm 构建流程。

## 项目预览

- 仓库地址：https://github.com/shhysy/db
- 网站入口：`dbtech_website_final/index.html`
- 当前改版开发分支：`redesign/blue-white-minimal`
- 正式默认分支：`main`

## 网站内容

网站首页目前包含以下主要板块：

| 模块 | 内容 |
| --- | --- |
| 首页首屏 | 企业定位、核心业务介绍及重点视觉展示 |
| 公司简介 | 企业介绍、发展与公司相关图片 |
| 核心解决方案 | eVTOL 物流、民用、紧急救援、建筑工程，以及汽车声学和 VMD 相关方案 |
| ANC 互动演示 | 展示发动机噪声、反相声波和残余噪声的示意波形，可调整转速并切换 ANC 状态 |
| 技术创新 | 展示自主研发、专利、系统集成和质量体系等信息 |
| 产品中心 | 展示飞行器、汽车声学模块及相关产品图片 |
| 新闻中心 | 展示企业荣誉、资质、合作和产品应用信息 |
| 联系我们 | 展示服务热线、邮箱和公司地址 |

## 技术栈

- **HTML5**：页面结构与内容。
- **CSS3**：页面布局、响应式适配、视觉主题及动画效果。
- **原生 JavaScript**：导航、滚动交互、解决方案弹窗、视觉动效和 ANC 音频演示。
- **Canvas**：粒子背景及 ANC 波形绘制。
- **Web Audio API**：生成 ANC 演示所使用的模拟声音。

项目无需安装前端框架或依赖包即可运行。浏览器需要支持现代 HTML5、Canvas 和 JavaScript；播放声音时还需要浏览器支持 Web Audio API，并允许用户进行交互后启动音频。

## 本地运行

### 方法一：直接打开

可以直接使用浏览器打开：

`dbtech_website_final/index.html`

如果遇到浏览器对本地资源或音频功能的限制，建议使用本地 HTTP 服务。

### 方法二：使用 Python 启动本地服务

确保电脑已安装 Python，在终端进入网站目录：

```bash
cd dbtech_website_final
python -m http.server 8000
```

然后在浏览器访问：

```text
http://localhost:8000
```

停止服务时，在终端按 `Ctrl + C`。

## 部署说明

这是一个静态网站，可以部署到支持静态文件托管的平台，例如 Cloudflare Pages、GitHub Pages 或其他 Web 服务器。

### Cloudflare Pages（无需构建的静态部署）

如果使用仓库连接方式部署，项目实际网站目录位于 `dbtech_website_final`，而不是仓库根目录。配置时请注意：

| 配置项 | 建议值 |
| --- | --- |
| 框架预设 | None / 无 |
| 构建命令 | 留空 |
| 输出目录 | `dbtech_website_final` |
| 根目录 | 仓库根目录（默认） |

部署前请确认目标分支包含需要发布的版本。若使用独立开发分支预览，正式生产分支仍建议保持为 `main`，待检查通过后再合并改版。

## 修改与维护指南

- **修改页面文字或模块结构**：编辑 `index.html`。
- **调整基础布局和原有组件**：编辑 `styles.css`。
- **调整蓝白商务风视觉**：优先编辑 `corporate.css`，避免不必要地覆盖原始样式。
- **调整滚动、粒子或卡片动效**：检查 `tech.js` 和 `tech.css`。
- **调整首屏动画**：检查 `hero-impact.js` 和 `hero-impact.css`。
- **调整 ANC 演示**：检查 `anc-audio.js` 及 `tech.css`、`tech-light.css`。
- **替换图片**：将图片放入 `images/`，并同步检查 HTML 中的图片路径和 alt 描述。

### 修改后建议检查

1. 首页首屏在桌面端和手机端是否正常显示。
2. 导航栏锚点、移动端菜单和返回顶部按钮是否正常。
3. 解决方案、产品及新闻卡片是否有错位或图片缺失。
4. ANC 波形、转速控制、开关和声音播放是否正常。
5. 页面是否存在横向滚动、控制台报错或明显加载问题。
6. 联系电话、邮箱、地址、备案信息及企业资质等内容是否准确。

## 注意事项

- ANC 波形和声音属于网页交互演示，不代表真实车辆测试结果或实际降噪性能。
- 企业专利数量、认证、客户合作、产品参数和新闻信息应以公司确认的资料为准；修改时不要自行推测或编造。
- 图片文件名和相对路径需要保持一致，避免替换素材后出现图片无法加载。
- 当前页面通过多个 CSS 文件按顺序加载样式，新增样式时需要留意加载顺序和选择器覆盖关系。
- 发布正式网站前，建议先在独立分支或预览环境完成桌面端、移动端和主要交互验收。
